# 🌿 Green Era — Eco Friendly Website

Green Era is a static eco-friendly website built using **HTML and CSS**.
The project focuses on promoting sustainable living by presenting products made from natural materials like **wood, bamboo, coconut, and soil**.

---

## ✨ Features

* 🏠 Home page with category selection
* 🌿 Bamboo Products Page
* 🥥 Coconut Products Page
* 🌱 Soil Products Page
* 🪵 Wood Products Page
* 📩 Contact Us Page
* 🌍 Save Environment Information Page
* 🔐 Login & Register UI Design
* 🎨 Modern Footer Design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome Icons

1. Download or clone this repository.
2. Open the folder.
3. Double click **index.html** to open the website in your browser.
